## Overview

BookHero is a strategic UX redesign project aiming to improve library resource utilization and support user co-construction through participatory digital experiences.

## Research Focus

- Why are library resources underutilized?
- How can UX support user participation and co-construction?
- What roles can digital platforms play in institutional knowledge ecosystems?

## Design Strategy

High-level strategy emerging from the research:
- Participation as value creation
- Discovery beyond search
- User curation as knowledge co-construction

## The Solution

BookHero proposes a redesigned UX system that enables discovery, participation, and user-driven curation of library resources.

## Key Outcomes

- Redesigned UX flows and interaction logic
- Participatory features supporting co-construction
- Validated prototype
